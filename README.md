# 🖼️ 이미지 변환기 (Image Converter)

> 브라우저에서 바로 실행되는 무설치 이미지 포맷 변환 도구  
> 다양한 이미지 파일을 글씨 깨짐 없이 변환합니다.

---

## ✨ 주요 특징

- **🚀 무설치 · 무서버** — HTML 파일 하나를 브라우저에서 열면 바로 실행됩니다
- **🔒 완전 로컬 처리** — 파일이 서버에 업로드되지 않으며, 모든 변환이 브라우저 내에서 처리됩니다
- **🔤 폰트 깨짐 없음** — 브라우저 렌더링 방식으로 로컬 컴퓨터에 저장된 폰트를 완벽하게 지원합니다
- **📐 다양한 크기 설정** — px / mm / cm 단위 지원, DPI 설정, 현수막·인쇄 규격 프리셋 내장
- **🔍 인터랙티브 미리보기** — 확대·축소·드래그·핀치줌, 원본/출력 전환 미리보기
- **📦 다중 형식 동시 변환** — 변환과 다운로드 단계가 분리되어 여러 형식을 한 번에 생성

---

## 📂 지원 형식

### 입력 (Input)
| 형식 | 확장자 | 비고 |
|------|--------|------|
| SVG | `.svg` | 나눔고딕 한글 폰트 완벽 지원 |
| PNG | `.png` | 투명도 지원 |
| JPG / JPEG | `.jpg`, `.jpeg` | |
| BMP | `.bmp` | |
| WebP | `.webp` | |
| TIFF | `.tif`, `.tiff` | JS 라이브러리(UTIF)로 디코딩 |
| GIF | `.gif` | |
| ICO | `.ico` | |
| AVIF | `.avif` | 브라우저 지원 필요 |

### 출력 (Output)
| 형식 | 특징 |
|------|------|
| PNG | 무손실, 투명도 지원 |
| JPG / JPEG | 손실 압축, 품질 조절 가능 |
| BMP | 무손실, 대용량 |
| WebP | 손실/무손실 선택 가능 |
| SVG | 래스터 이미지를 SVG 안에 임베드 |
| TIFF | 무압축 TIFF, 인쇄용 |
| GIF | 256색 제한 (미지원 시 PNG 대체) |
| ICO | 아이콘 전용, 256px 이하 자동 조정 |
| AVIF | 최신 압축 포맷 (미지원 시 PNG 대체) |

## 🚀 사용 방법

### 1. 파일 열기
`image_converter.html` 파일을 다운로드한 후, 브라우저(Chrome / Edge / Firefox 권장)에서 바로 엽니다.

> **인터넷 연결 필요**: Google Fonts(나눔고딕)와 TIFF 처리 라이브러리(UTIF)를 CDN에서 로드합니다.

---

### 2. 파일 불러오기 (Step 1)
- 파일을 **드래그&드롭**하거나, 영역을 **클릭**하여 파일을 선택합니다
- 업로드 후 원본 크기와 파일 형식이 자동으로 표시됩니다

---

### 3. 출력 크기 설정 (Step 2)

**프리셋 선택** 또는 직접 입력:

| 프리셋 | 크기 |
|--------|------|
| 가로현수막 3000×1000 | 3000 × 1000 px |
| 가로현수막 4000×1500 | 4000 × 1500 px |
| 세로현수막 2000×6000 | 2000 × 6000 px |
| FHD | 1920 × 1080 px |
| 4K | 3840 × 2160 px |
| A4 300dpi | 2480 × 3508 px |
| A4 600dpi | 4960 × 7016 px |
| 원본 크기 | 원본 파일 해상도 그대로 |

**단위**: px / mm / cm 선택 가능  
**DPI**: 72 / 96 / 150 / 300 / 600 선택 가능 (현수막 권장: 150, 인쇄 권장: 300)  
**비율 옵션**:
- 늘리기 (비율 무시)
- 비율 유지 — Contain (기본값)
- 비율 유지 — Cover (잘라냄)
- 원본 크기 그대로

---

### 4. 출력 형식 선택 (Step 3)
- 원하는 출력 형식을 **복수 선택** 가능합니다
- JPG / JPEG / WebP는 품질 슬라이더(10%–100%)로 압축률 조절 가능합니다
- 배경색을 흰색 / 투명(PNG·WebP·SVG 전용) / 사용자 지정 색상 중 선택합니다

---

### 5. 미리보기 (Step 4)

| 기능 | 조작 방법 |
|------|-----------|
| 확대 | `＋ 확대` 버튼 또는 마우스 휠 위 |
| 축소 | `－ 축소` 버튼 또는 마우스 휠 아래 |
| 이동 (스크롤) | 뷰어 안에서 드래그 |
| 화면 맞춤 | `⊡ 화면 맞춤` 버튼 또는 더블클릭 |
| 100% 보기 | `100%` 버튼 |
| 원본 1:1 | `1:1 원본` 버튼 |
| 터치 핀치줌 | 두 손가락으로 핀치인/아웃 |
| 원본 미리보기 | `원본 미리보기` 탭 클릭 |
| 출력 미리보기 | `출력 미리보기` 탭 클릭 |
| 새로고침 | `🔄 새로고침` 버튼 |

---

### 6. 변환 (Step 5)
- `⚡ 변환 시작` 버튼을 클릭합니다
- 진행률 바에서 변환 진행 상황을 확인할 수 있습니다

---

### 7. 다운로드 (Step 6)
- 변환 완료 후 **Step 6 다운로드** 섹션이 자동으로 나타납니다
- 파일별 개별 **다운로드** 버튼으로 원하는 형식만 저장합니다
- 2개 이상 변환 시 `⬇ 전체 일괄 다운로드` 버튼이 활성화됩니다

---

## 💡 SVG 현수막 & 한글 폰트 지원 안내

Python(`cairosvg` 등)으로 SVG를 변환할 때 특수 한글 폰트가 시스템에 설치되어 있지 않으면 기본 폰트로 대체되어 글씨와 레이아웃이 틀어지는 문제가 발생합니다.

이 도구는 **브라우저가 직접 SVG를 렌더링**하기 때문에:
- 자동으로 폰트를 불러옵니다
- SVG 파일 내 `font-family: 'font'` 지정을 그대로 반영합니다
- 시스템에 폰트가 설치되어 있지 않아도 동일하게 출력됩니다

## ⚠️ 참고 사항

- **TIFF 출력**: 무압축(Uncompressed) TIFF로 생성됩니다. 파일 크기가 클 수 있습니다.
- **GIF / ICO / AVIF**: 브라우저가 해당 형식의 인코딩을 지원하지 않을 경우 PNG로 자동 대체되며, 경고 메시지가 표시됩니다.
- **매우 큰 해상도**: 4000px 이상의 이미지는 브라우저 메모리 한도에 따라 처리 시간이 길어지거나 실패할 수 있습니다. 확인 창이 표시됩니다.
- **SVG 내 외부 이미지(`<image>` 태그)**: CORS 정책으로 인해 Canvas가 오염될 수 있습니다. 외부 이미지를 Base64로 인라인 임베드하는 것을 권장합니다.
- **인터넷 연결**: Google Fonts 및 UTIF 라이브러리 로딩을 위해 인터넷 연결이 필요합니다.
